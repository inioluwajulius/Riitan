# RÍÌTÀN — Maison de Haute Joaillerie

> *"The shape of a woman, rendered in gold."*  
> Sculptural 18k solid recycled gold jewellery rooted in Yoruba heritage and architectural modernity.

---

## 🌟 Overview

**RÍÌTÀN** is a high-jewelry web platform designed with quiet luxury aesthetics, bespoke lost-wax metallurgy storytelling, and interactive client experiences.

### Key Features
- **Interactive Gold Motifs & Canvas**: Shimmering ambient canvas and 360-feel sculptural jewelry visualizer with live alloy switching (*18k Yellow Gold, Rose Gold, White Gold*).
- **The Signature Silhouettes**: *The Split Loop*, *The Soft Triangle*, and *The Double Flow*.
- **The Four Chapters**: *Presence*, *Tide*, *Lineage*, and *Gilt* collections with category filtering and piece quick-view modals.
- **Live Multi-Currency Engine**: Instant conversion across `USD ($)`, `GBP (£)`, `EUR (€)`, and `NGN (₦)`.
- **Editorial Lookbook**: High-fashion campaign shoots with interactive fullscreen Lightbox.
- **Lost-Wax Atelier**: 4-stage ancestral casting journey and sustainable craft pillars.
- **House Services & Bespoke Reservation**: Private styling, consultations, custom sourcing, and red-carpet rentals.
- **Private Salon Dispatch**: Live time clocks for Lagos (WAT) and London (GMT) ateliers and newsletter registration.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the digital platform.

### 3. Build for Production
```bash
npm run build
```
